# Crow Avatar 2D v0.4 — A/B実装比較仕様（固定）

この仕様は Chat 実装と Work 実装を公平に比較するための共通仕様です。
両者は同じ開始コミット・同じ要求から別ブランチで実装します。

## 目的
Galaxy実機で自然に見える簡易2D顔リグを作る。
完成顔の差し替えではなく、動く部位を独立して扱う。

## 必須構造

### BODY
- 肩・服・胸
- 顔追従では動かさない
- ごく小さい呼吸のみ

### HEAD
- 髪・頭羽毛・顔輪郭・固定上嘴
- yaw / pitch / roll のみ追従
- 肩を含めない

### LEFT_EYE / RIGHT_EYE
最低限:
- 元の眼球領域
- 上まぶた
- 下まぶた
- 左右を独立制御
- 元の目の輪郭に合わせる
- 完全閉眼時に白目・虹彩が見えない
- 別形状の黒帯を描き足す方式は禁止

瞬膜:
- 実装してよい
- 通常瞬きと同時に閉じる補助扱い
- 単独機能は必須ではない

### MOUTH
3レイヤー:
1. mouth_inside — 一番奥
2. lower_beak — 可動
3. upper_beak — 固定・最前面

必須:
- 上嘴を口開閉で動かさない
- 下嘴だけを口角付近の支点で回転
- 必要なら下＋後方へ微移動
- 逆三角形で上嘴まで切り抜く方式は禁止
- 口中心がズレない

## トラッキング入力
MediaPipe Face Landmarker:
- yaw
- pitch
- roll
- eyeBlinkLeft
- eyeBlinkRight
- jawOpen

## 動作
- yaw/pitch/roll -> HEAD
- eyeBlinkLeft -> 左まぶた
- eyeBlinkRight -> 右まぶた
- jawOpen -> lower_beak
- BODY -> カメラとは無関係な呼吸

## 可動域
v0.3よりやや広くする:
- yaw: 約1.2〜1.4倍
- pitch: 約1.2倍
- roll: 現状〜少し増加
不自然な首切断が出る場合は可動域より境界自然さを優先する。

## 配信
- UIを隠す配信画面モードを維持
- 前面カメラはCrow Avatarが使用
- YouTube等は画面キャプチャ方式を想定

## 実機合格条件
1. 左右・上下・傾きで肩が頭に付いてこない
2. 左目だけ閉じられる
3. 右目だけ閉じられる
4. 完全閉眼で虹彩・白目が残らない
5. 元の目の形とまぶた形状が一致して見える
6. 上嘴が固定
7. 下嘴だけが開閉
8. 口内が奥に見える
9. 口中心がズレない
10. 髪・目・顔輪郭が口開閉で変化しない
11. 30秒以上安定
12. 配信画面モードが動く

## 禁止
- 頭全体の表情画像切替
- 黒帯による閉眼
- 上嘴を含む口差分
- 左右瞬きを1値に統合
- 肩をHEAD可動領域に含める

## 比較ルール
- Chat: branch `experiment/chat-v04`
- Work: branch `experiment/work-v04`
- 両者はこの仕様が入った同じコミットから開始する
- 相手ブランチの実装を参照・コピーしない
- 比較項目: 自然さ、破綻、実装構造、APK安定性、修正回数
