# Avatar Lab 実証計画 — 2D → 3D

この文書の目的は「知っている」ではなく「実機で使える」を判定することです。

## 合格条件

### 2D
以下が Galaxy 実機で同時に成立したら「簡易2Dリグを使いこなせる」と判定します。

1. 頭だけが左右・上下・傾きに追従する
2. 肩・服・胴体は頭に引っ張られない
3. 左右のまばたきを別々に扱える
4. 口は頭画像の差し替えではなく、口パーツだけで開閉する
5. 口を開いても目・髪・輪郭がズレない
6. 胴体は独立して小さな呼吸だけをする
7. 30秒以上動かして破綻・クラッシュがない
8. 配信画面モードで操作UIを隠せる

### 3D
2Dの合格後に別フォルダで実証します。

1. Head/Neck bone が顔向きに追従
2. 左右Blinkを独立 BlendShape / Shape Key に接続
3. Jaw/Open mouth を独立制御
4. Eye gaze を独立制御
5. Galaxy実機でリアルタイム追従
6. 配信用画面として安定動作

## 2Dの正しい構造

完成顔3枚を差し替える方式は廃止します。

- BODY: 肩・服・胸。呼吸だけ。
- HEAD_BASE: 髪・羽・顔・固定上嘴。頭追従。
- EYE_L: 左目だけ
  - open
  - closed
- EYE_R: 右目だけ
  - open
  - closed
- LOWER_BEAK: 下嘴だけ
  - closed
  - open
- MOUTH_INSIDE: 必要なら口内だけ

HEAD_BASE以下は同じ頭座標系に置きます。
BODYは別座標系です。

## 入力

MediaPipe Face Landmarker

- yaw/pitch/roll -> HEAD_BASEグループ
- eyeBlinkLeft -> EYE_L
- eyeBlinkRight -> EYE_R
- jawOpen -> LOWER_BEAK
- BODY -> カメラ入力と無関係な呼吸

## 重要な失敗防止ルール

- 表情差分の「頭まるごと交換」をしない
- 肩を頭のclip領域に入れない
- 左右まばたきを max() で1値にまとめない
- 生成AIの別画像を、そのまま差し替え素材にしない
- 生成素材は同一キャンバス上のパーツとして検証してから採用
- 画像を更新したら必ず実機APKで確認する

## ユーザーがスマホですること

PC作業は不要です。

1. ChatGPTから渡されたAPKをインストール
2. カメラ許可
3. 次の5動作を各1回試す
   - 顔を右/左
   - 顔を上/下
   - 首を傾ける
   - 左目だけ閉じる / 右目だけ閉じる
   - 口を小さく / 大きく開く
4. 破綻したところだけスクリーンショットか短い説明で返す

コード、ビルド、GitHub Actions、ログ解析はこちらで行います。

## 配信

第1段階:
- Crow Avatar が前面カメラを占有
- YouTube等はスマホ画面をScreencast
- 「配信画面にする」でUIを隠す

第2段階:
- アプリ自身に映像エンコード/RTMP送信を追加
- Avatar描画 -> encoder -> RTMP
- 配信アプリとのカメラ競合をなくす
