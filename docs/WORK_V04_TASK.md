## 最重要
- `docs/CROW_V04_AB_SPEC.md` を唯一の実装要求として読む
- `experiment/chat-v04` のコード・コミット・差分を見ない

## ゴール

## 作業
1. 現状コードと素材を調査
2. 必要なら素材構造を作り直す
3. 目を左右独立で自然に閉じる
4. 上嘴固定、口内・下嘴を独立させる
5. BODYとHEADを分離
6. 顔追従・配信画面モードを維持
7. GitHub ActionsでAPKビルド成功まで直す
8. 成果物APKと実装上の判断・未解決点をまとめる
